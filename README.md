# 课程资料整理工具

一个计划用 Python 编写的命令行工具，帮助学生按课程和日期整理学习资料。

## 项目状态

开发中，目前仅完成设计，尚未实现功能。本仓库是「开源软件开发与实践」课程的许可证与 README 练习项目。

## 安装或获取

当前为设计阶段，暂无安装包，也不需要安装依赖。

请先阅读设计说明：[docs/design.md](docs/design.md)。

## 使用说明

功能尚未实现，现在没有可以执行的操作。

计划中的最小操作是：把学习资料放进一个目录，再按课程和日期整理并查看结果。具体计划见 [docs/design.md](docs/design.md)。在程序实现之前，不要运行文档中的计划命令。

## 项目结构与依赖

当前版本包含：

- `README.md`：项目说明
- `LICENSE`：MIT 许可证全文
- `compliance-analysis.md`：许可证比较和选择理由
- `docs/design.md`：尚未实现的功能计划

当前版本未引入第三方素材，也没有第三方代码、图片、字体或数据依赖。

## 如何贡献

发现问题或有建议时：

1. 打开本仓库的 Issues：`https://github.com/你的用户名/你的学号-license-lab/issues`。
2. 新建 Issue，写清问题、你期望的结果，以及当前仓库所处的设计阶段。
3. 在实现开始之前，先通过 Issue 讨论，不直接提交功能代码。
